# 《九九小車手》設計文件

日期:2026-07-29
狀態:已由 Ted 核可設計方向,待審閱本文件

## 目的

做一個九九乘法表練習遊戲給剛開始學乘法(部分段已會)的小朋友玩。玩法結合小朋友喜歡的兩種遊戲:開車遊戲(核心操作)與 Vampire Survivors(單局升級三選一)。在 iPad Safari 上以網頁(PWA)方式遊玩,不需下載 App。

## 成功標準

- 小朋友能在 iPad 上不需教學就會玩(唯一操作:換車道)
- 答錯有學習回饋(顯示正確答案),且錯題會再次出現直到熟練
- 家長可控制練習範圍(選段)
- 部署後開網址即玩,加入主畫面後離線可玩
- 託管成本 $0/月

## 非目標(v1 不做)

- 跨局永久收集(解鎖車款/商店)——留待二期
- 帳號系統、後端、雲端存檔——一律 localStorage
- 家長儀表板/答題統計報表
- App Store 上架

## 畫面流程

```
首頁 ──開始──▶ 遊戲中 ──每過一關──▶ 升級三選一 ──▶ 回到遊戲(更快)
 │                │
 選段設定          愛心歸零
 (勾 1~9 的段)       │
 │                ▼
 最高分顯示 ◀──── 結算畫面(分數/金幣/答對率)
```

## 核心玩法

### 公路與操作

- 三車道直向捲動公路,車子固定在畫面下方 1/4 處,自動前進(以背景捲動速度呈現)。
- 唯一操作:**點擊目標車道**或**左右滑動**,車子平滑移到該車道(約 150ms 補間)。
- 直式構圖為主;橫拿 iPad 時畫面 letterbox 置中,遊戲區維持直式比例。

### 題目與門

- 畫面上方常駐顯示當前題目,例如 `3 × 5 = ?`,字體大。
- 每隔一段路出現一排**三個門**橫跨三車道,各寫一個大數字(一個正確答案 + 兩個干擾項,隨機分配車道)。
- 門與門之間的間隔:以基礎車速換算約 4.5 秒到達;**下一題在前一排門結算的當下就先顯示**,思考時間約等於一整個門距。車速加快後間隔時間等比縮短。(v1.1 調整:原設計 4 秒、題目於門生成時才顯示,實測反應時間不足)
- **通過正確的門**:得分 `100 × 連擊倍率`,慶祝音效 + 粒子特效,連擊 +1。
- **通過錯誤的門**:扣 1 顆愛心、連擊歸零、遊戲慢動作 2 秒並以大字顯示 `3 × 5 = 15` 的完整正確算式(學習時刻),該題進入複習佇列。
- 連擊倍率 = 連續答對題數,上限 ×5。

### 愛心與結束

- 開局 3 顆愛心,答錯扣 1(護盾可抵擋,見升級)。愛心歸零 → 結算畫面。
- 結算畫面顯示:本局分數、金幣數、答對率、最高分(localStorage),按鈕「再玩一次」「回首頁」。

### 金幣

- 兩排門之間的路面隨機生成金幣串(沿單一車道排列 3~6 枚,偶爾跨車道弧線)。
- 開過去收集,每枚 +10 分;有磁鐵升級時鄰近車道的金幣自動吸附。
- 金幣只計入本局分數,不跨局保留(v1 無永久收集)。

### 關卡與難度曲線

- 每通過 10 排門(不論開對或開錯的門都計數)= 過一關。過關時跳出升級三選一(遊戲暫停)。
- 每過一關基礎車速 +5%,上限為初始速度的 1.6 倍。(v1.1 調整:原 +8%/2 倍,對剛學乘法的小朋友太快)
- 關數無上限,直到愛心歸零。

## 出題引擎

### 選段

- 首頁提供 1~9 的段勾選(至少勾一段),預設勾 2、3、5。
- 選擇存 localStorage,下次開啟沿用。

### 練習模式「用點的」(v1.3 新增)

- 車速選單的第一檔 🐣「用點的」,給完全還不會乘法的小朋友:
  - 世界完全靜止:門滑入後停在題目下方的停等線,**不限思考時間**
  - 點哪道門,車子就開過去那道門;通過後自動滑到下一題再停住
  - 獎勵跟其他檔位一樣(2026-11-19 改;原本沒有金幣與升級):答對後車子前方同一車道出 3 枚金幣,換題滑行時自動吃到(金幣不在答題前出現,避免洩漏答案);每 10 道門升級三選一,過關另外自動回復 1 顆愛心
  - 三選一不會出現慢速門與磁鐵(這個模式沒有車速與選道,兩者沒有作用)
  - 愛心、分數、連擊、答錯學習時刻、錯題複習佇列照舊
  - 防誤觸:只有門停好等待時,點擊才算出發(換題動畫或慶祝中點擊只換車道不前進)

### 車速檔位(v1.2 新增)

- 首頁提供初始速度檔位:🐢 慢慢開(170 px/s)/ 🚗 普通(220)/ 🚀 飆速(280)/ 😈 超高速(400,v1.4 新增,給大人玩;思考時間約 2.5 秒、頂速時約 1.5 秒),預設慢慢開。
- 門距固定,所以檔位越慢思考時間越長:慢 ≈ 5.8 秒/門、普通 ≈ 4.5 秒、飆速 ≈ 3.5 秒。
- 每關 +5%、上限 1.6 倍的成長曲線以所選檔位為基礎。
- 選擇存 localStorage(settings.speed);舊版存檔缺欄位時自動補預設值。

### 題目生成

- 題目形式:`a × b = ?`,a 為勾選的段,b 為 1~9 均勻隨機。
- 正常題目從勾選的段中均勻抽段;複習佇列有到期題目時優先出複習題。

### 干擾項生成(關鍵設計)

錯誤選項模擬真實的背誦錯誤,而非亂數:

- 候選池:`a×(b−1)`、`a×(b+1)`、`(a−1)×b`、`(a+1)×b`
- 從候選池隨機取 2 個,需滿足:值 > 0、彼此相異、且 ≠ 正確答案。
- 候選不足時(如 1×1),以正確答案 ±1~3 的隨機值補足。
- 三個答案隨機分配到三個門(車道)。

### 複習佇列(自動適應)

- 答錯的題目 `(a, b)` 進入複習佇列,安排在 3~5 題後(隨機)重新出現。
- 複習題**連續答對 2 次**才移出佇列;再答錯則重新排程並重置計數。
- 只出勾選的段:沒勾選的段的複習題這局不出、也不倒數,存檔保留,重新勾選後再複習(2026-11-19 修正)。
- 佇列持久化到 localStorage,跨局、跨日延續——上次的弱點下次接著練。

### localStorage 鍵

| 鍵 | 內容 |
|----|------|
| `99racer.settings` | 勾選的段、靜音狀態 |
| `99racer.highscore` | 最高分 |
| `99racer.review` | 複習佇列(題目、連對次數) |

所有 localStorage 讀寫包 try/catch(Safari 無痕模式會丟例外),失敗時退回記憶體內狀態,遊戲照常可玩。

## 單局升級(Vampire Survivors 元素)

每過一關從升級池抽 3 個相異選項供三選一,選完立即生效並繼續遊戲:

| 升級 | 效果 | 持續 |
|------|------|------|
| 🧲 磁鐵 | 鄰近車道金幣自動吸附 | 本局剩餘時間 |
| 🛡️ 護盾 | 抵擋一次答錯(不扣愛心、不斷連擊,該題仍進複習佇列) | 一次性,可重複獲得疊加,上限 2 層 |
| ⭐ 雙倍分數 | 門的得分 ×2 | 僅下一關 |
| 🐢 慢速門 | 車速暫時回到初始速度 | 僅下一關 |
| 💰 金幣加倍 | 金幣 +20/枚 | 本局剩餘時間 |

- 已持有的永久型升級(磁鐵、金幣加倍)從池中移除;護盾已達 2 層時同樣移除。
- 池中剩不足 3 個時,以「❤️ 回復 1 顆愛心(上限 3)」補位。
- 死亡後所有升級歸零,只留最高分——單局內成長、跨局歸零,即 Vampire Survivors 的核心循環。

## 技術架構

純 HTML + Canvas 2D、零框架、零 build 步驟。ES modules(iPad Safari 原生支援),同一份邏輯程式碼可同時在瀏覽器與 node 測試中運行。

```
9x9/
├── index.html          # 入口;首頁/升級/結算 UI 用 DOM,遊戲畫面用 Canvas
├── style.css
├── js/
│   ├── questions.js    # 出題引擎:選段、干擾項、複習佇列(純邏輯,零 DOM 依賴)
│   ├── upgrades.js     # 升級池與效果狀態(純邏輯,零 DOM 依賴)
│   ├── game.js         # 遊戲迴圈(requestAnimationFrame)、實體生成、碰撞、繪製
│   ├── audio.js        # WebAudio 合成音效(不用音檔):答對、答錯、金幣、過關、引擎
│   └── storage.js      # localStorage 包裝(try/catch、預設值)
├── sw.js               # Service worker:cache-first,離線可玩
├── manifest.json       # PWA:名稱、圖示、display: standalone、直式方向
└── icons/              # 192/512 px 圖示 + apple-touch-icon
```

- 視覺風格:扁平卡通,Canvas 幾何繪製(圓角矩形車身、漸層路面),不依賴外部圖片素材,確保載入 < 1 秒。
- 介面文字:繁體中文,量少字大。

## iPad / iOS Safari 適配

- `viewport` meta:`width=device-width, initial-scale=1, viewport-fit=cover`;`touch-action: none` + 阻止 `touchmove` 預設行為,鎖住捲動回彈與雙擊縮放。
- Canvas 尺寸依 `devicePixelRatio` 縮放,Retina 不糊。
- WebAudio 的 `AudioContext` 在第一次觸碰事件中 `resume()`(iOS 自動播放限制);提供靜音按鈕。
- `manifest.json` + `apple-touch-icon` + `apple-mobile-web-app-capable`:加入主畫面後全螢幕、自訂圖示。
- Service worker cache-first:第一次載入後離線可玩;檔案清單寫死於 sw.js,改版時 bump cache 版本號。
- 所有資源路徑使用**相對路徑**(GitHub Pages 部署在 `/<repo>/` 子路徑下)。

## 錯誤處理

- localStorage 不可用 → 記憶體 fallback,功能照常、只是不記錄。
- AudioContext 建立失敗 → 靜音模式,不阻斷遊戲。
- 視窗尺寸/方向改變 → 重算 canvas 尺寸與車道座標,遊戲中觸發則暫停一幀重繪。

## 測試策略

- **單元測試**(`node --test`,零額外套件):
  - `questions.js`:干擾項規則(不重複、非負、≠ 正解、來自候選池)、選段過濾、複習佇列排程/移出/重置邏輯。
  - `upgrades.js`:抽選不重複、已持有移除、護盾疊加上限、補位邏輯。
  - `storage.js`:localStorage 例外時的 fallback。
- **手動驗證**:桌機瀏覽器開發時即時試玩;里程碑時以實機 iPad Safari 驗證觸控、音效、PWA 安裝、離線。

- 無 build 步驟,push 即上線。網址:`https://<GitHub 帳號>.github.io/9x9/`。
